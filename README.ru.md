## 🌌 Обзор Проекта

**KostromAi44** — это корпоративный открытый визуальный оркестратор и среда исполнения для конструирования, тестирования, отладки и эксплуатации автономных мультиагентных ИИ-систем. Основанный на топологическом планировщике Кана, параллельном Promise-пулинге, изолированной Docker-песочнице и совместной работе в реальном времени, KostromAi44 объединяет удобство визуального конструктора и надёжность промышленного бэкенда.

Разворачиваете ли вы агентов службы поддержки, автоматических рецензентов кода, сложные гибридные RAG-системы или конвейеры обработки данных — KostromAi44 превратит визуальные графы в защищённые REST/WebSocket микросервисы в один клик.

## 🎯 Почему KostromAi44?

| Проблема в ИИ-Инженерии | Традиционные Решения | Решение KostromAi44 |
| :--- | :--- | :--- |
| **Сложность Оркестрации LLM** | **No-Code Инструменты** (Zapier, Make): Ограничены, не справляются со сложными ветвлениями, состояниями и кодом. | **Визуальный DAG Canvas + Код**: Узлы с кастомным кодом JS/Python, исполняемые внутри изолированных контейнеров. |
| **Затраты на Разработку Бэкенда** | **Фреймворки** (LangChain, CrewAI): Недели написания кода бэкенда, очередей, логики повторов и мониторинга. | **Деплой в API в Один Клик**: Мгновенная конверсия визуальных графов в версионируемые REST и WebSocket эндпоинты `/api/v1`. |
| **Зависимость от Провайдера** | **SaaS Платформы** (Relevance AI, Flowise SaaS): От $500/мес, закрытый код, риски утечки данных. | **100% Open-Source & Self-Hosted**: Лицензия MIT, полный контроль над данными, запуск в своём облаке или On-Premise. |
| **Опасность Недоверенного Кода** | **Прямое Исполнение**: Уязвимость к бесконечным циклам, RCE-атакам и утечкам файловой системы. | **Изолированные Docker Песочницы**: Root-less контейнеры с ограничениями RAM, read-only ФС и сброшенными capabilities. |

## ⚡ Ключевая Архитектура и Возможности

### 🧠 **Топологический Параллельный Планировщик DAG**
Благодаря алгоритму Кана и асинхронному пулу Promise, KostromAi44 выполняет независимые узлы конвейера параллельно с гарантированным соблюдением порядка. Нулевой риск дедлоков, детерминированное выполнение и минимальная задержка.

```mermaid
graph LR
    A[Приём Данных] --> B[Агент Классификации]
    A --> C[Агент Валидации]
    B --> D[Маршрутизатор]
    C --> D
    D --> E[Агент Исполнения]
    D --> F[Логер Аудита]
```

### 🛡️ **Защищённая Песочница Docker**
Узлы выполнения кода запускаются внутри контейнеров Docker с комплексной защитой:
- `--cap-drop ALL` — Полный сброс привилегий ядра Linux.
- `--network none` — Блокировка внешнего сетевого доступа (если не разрешено явно).
- `--read-only` — Неизменяемая корневая файловая система.
- `64 MB RAM` — Строгий лимит оперативной памяти.
- `5s Timeout` — Автоматическое завершение зависших процессов.

### 🔄 **Самовосстановление с Честной Телеметрией**
Ограничения по тарифам и сбои LLM-провайдеров автоматически компенсируются:
1. **Экспоненциальный Откат**: Автоматические повторы с джиттером.
2. **Горячая Замена Провайдера**: Автоматическое переключение (OpenAI → Claude → Gemini → Local Ollama).
3. **Прозрачный Аудит**: Статус `completed_with_warning` исключает скрытые ошибки.

### 👥 **Совместная Работа в Реальном Времени**
На базе Socket.io с комнатной изоляцией присутствия:
- Отслеживание курсоров пользователей в реальном времени с цветными аватарами.
- Оптимистичная блокировка узлов для предотвращения конфликтов редактирования.
- Интерфейс разрешения конфликтов при командной разработке.

### 🕑 **Отладчик «Путешествие во Времени»**
Каждое изменение состояния графа создает неизменяемый снимок. Перематывайте выполнение вперёд и назад, сравнивайте входы и выходы узлов для мгновенной отладки.

## 🚀 Быстрый Старт

### Вариант 1: Docker Compose (Рекомендуется)

Запуск полного стека менее чем за 60 секунд:

```bash
# 1. Клонирование репозитория
git clone https://github.com/ppiiyo/AgentForge44.git kostromai44
cd kostromai44

# 2. Запуск контейнеров
docker compose up -d --build

# 3. Приложение доступно по адресу http://localhost:3000
```

*Состав Стека:* Nginx Reverse Proxy → Express API Gateway → Node.js Backend → PostgreSQL → Redis → Docker Sandbox Runner.

---

### Вариант 2: Локальная Разработка

Требования: **Node.js ≥ 22.0.0**, **npm ≥ 10.0.0**, и **Docker** (опционально, для узлов кода).

```bash
# 1. Клонирование и установка зависимостей
git clone https://github.com/ppiiyo/AgentForge44.git kostromai44
cd kostromai44
npm install

# 2. Настройка переменных окружения
cp .env.example .env

# Генерация безопасных ключей (минимум 32 символа)
export JWT_SECRET=$(openssl rand -base64 48)
export ENCRYPTION_MASTER_KEY=$(openssl rand -base64 48)

# 3. Инициализация Базы Данных и Шаблонов
npm run db:push     # Применение схемы (SQLite по умолчанию)
npm run db:seed     # Заполнение маркетплейса шаблонами

# 4. Запуск Сервера Разработки
npm run dev
```

Откройте **`http://localhost:3000`**. Первый зарегистрированный пользователь автоматически получает права **Администратора**.

## 🔌 Справочник API

Все маршруты версионированы с префиксом **`/api/v1`** (с поддержкой обратной совместимости через **`/api`**).

| Метод | Эндпоинт | Описание | Авторизация |
| :--- | :--- | :--- | :---: |
| `POST` | `/api/v1/auth/register` | Регистрация аккаунта (1-й пользователь = Admin) | Нет |
| `POST` | `/api/v1/auth/login` | Аутентификация и получение JWT-токена | Нет |
| `POST` | `/api/v1/auth/logout` | Отзыв JWT-токена через Redis JTI blacklist | Да |
| `POST` | `/api/v1/execute/graph` | Синхронный запуск структуры графа DAG | Да |
| `POST` | `/api/v1/execute/blueprint` | Запуск сохранённого шаблона конвейера по ID | Да |
| `POST` | `/api/v1/runs` | Отправка асинхронной фоновой задачи | Да |
| `GET` | `/api/v1/runs/:id` | Запрос статуса, логов и состояния выполнения | Да |
| `GET` | `/api/v1/health` | Проверка состояния системы и компонентов | Нет |
| `GET` | `/metrics` | Эндпоинт метрик Prometheus | Да |

Интерактивная документация Swagger OpenAPI доступна по адресу **`/api-docs`**.

## 🔒 Корпоративная Безопасность

- **Сетевая Защита**: Nonce Content Security Policy (CSP), защита от SSRF с жестким пиннингом IP, HSTS.
- **Аутентификация**: Проверка JWT с отзывом через Redis `jti` blacklist; ролевая модель (RBAC).
- **Шифрование Данных**: Алгоритм AES-256-GCM для внешних ключей API в БД; TLS 1.3 при передаче.
- **Безопасность Исполнения**: Изолированные root-less контейнеры Docker для недоверенного кода.
- **Аудит**: Неизменяемые журналы аудита для каждого запуска конвейера.
